1. 三条硬约束

01

没有触屏，只有三颗键

孩子没法「点拇指」。所以 UP=认识（拇指）、DOWN=不记得（问号），一次按键直接表达，不引入「先移动焦点再确认」的概念。

02

一张全屏位图吃掉内存

240×320×2 B ≈ 150 KiB，而 C3 全部 SRAM 约 400 KiB。不存图片，只存笔画指令，LVGL 现画。按钮缩小后，线图反而能画得更大更清楚。

03

在线服务不回传结构化结果

xiaozhi.me 会下发 stt 转写文本和 llm 表情，但不会发自定义 custom。判定放在设备本地做，反而更简单、更快、零额外服务。

v0.2 一句话：两条链路彻底解耦——语音走小智在线服务（ASR / LLM / TTS），词表、线图、发音、进度走飞牛 NAS 局域网。设备端只做一个薄壳，换词表不刷固件；断网时内置保底包仍能看图、听音、按两个键，只是跟读和问小智暂不可用。

5. 线图方案（按钮缩小后，图反而更清楚）

你提到的「AI 针对幼儿园生成简单线图」方向对，但不要让 AI 输出位图。一张 240×320 RGB565 位图约 150 KiB，而一幅简笔线图的指令串只要 100–400 字节，相差约 500 倍。按钮压到 1/4 屏以内后，绘图区从原来的约 100×100 放大到约 160×160，线条辨识度对 6 岁孩子更友好。

5.1 笔画指令格式（v0.2 简化：只画直线和圆，曲线用折线近似）

// 每条 5 字节，坐标归一化 0..200，绘制时线性映射到屏幕绘图区
// [opcode:1][x1:1][y1:1][x2:1][y2:1]
OP_LINE   = 1   // (x1,y1) → (x2,y2)
OP_CIRCLE = 2   // 圆心 (x1,y1)，半径 x2
OP_RECT   = 3   // 对角 (x1,y1)-(x2,y2)
OP_DOT    = 4   // 实心点 (x1,y1)，半径 x2（画眼睛、斑点）
OP_END    = 255

// 一个词：magic(2) + stroke_count(1) + n×5 B
// apple ≈ 17 笔 ≈ 88 B；20 词的整个单元线图 ≈ 1.8 KiB
// 曲线（苹果轮廓、月牙、云朵）由备课脚本扁平成 8~12 段短 LINE，
// 所以设备端渲染器连 arc 都不用实现，只要 lv_line + 画圆。

已生成 /workspace/words/lineart/apple.strokes.json 作为可读示例；打包脚本会把它转成上面的 5 字节二进制。生成曲线 → 折线扁平化这一步放在 NAS 侧，设备零解析负担。

8. 「AI 判断读得对不对」— 在线服务器下的做法 已重做

用 xiaozhi.me 就没有 custom 回传，但协议里服务端本来就会把 ASR 转写文本通过 type:stt 下发到设备显示字幕。设备拿到这段文字后，本地比对目标词即可——不需要改服务端、不需要自建、不需要额外一次 LLM 调用。

环节做法
上行按 OK → 设备发 listen:start + Opus 音频（原固件链路，零改动）
ASR在线服务转写，下发 {"type":"stt","text":"appo"}
判定设备本地：小写化 → 去空格标点 → 折叠重复字母 → 与目标词算编辑距离（≤2）或前缀匹配（长度≥3）；再加一张童音宽容表（appo / apo / aplo → apple）。约 30 行 C、几百字节
反馈显示 ⑤ 或 ⑥ + 播放本地预录鼓励音；随后发 abort 掐掉本轮 TTS，避免小智说出和屏幕图案矛盾的话
兜底stt 未下发、文本为空、转成中文 → 一律显示「再听一次」，不判错、不扣分
进度本地 NVS 记录 status / score / reviewAt，联网时批量回写 NAS
// 在线服务 → 设备（设备本来就收得到，用于字幕）
{ "session_id":"...", "type":"stt", "text":"appo" }
{ "session_id":"...", "type":"llm", "emotion":"happy", "text":"😀" }

// 设备 → 在线服务：跟读结束，掐掉本轮回复
{ "session_id":"...", "type":"abort", "reason":"word_eval_done" }

// 「问小智」上下文注入尝试（需实机验证，见第 13 节）
{ "type":"listen", "state":"detect", "text":"单词模式 apple 用六岁小朋友能懂的话讲一下" }
这样反而更好：零额外服务、零 token、零云端延迟、不用碰官方服务端配置；精度靠「宽容表 + 只给正反馈」兜住——判不准就再听一次，孩子不会受挫。将来若想要 LLM 级童音复判，只要换 word_proto.c 一层接自建服务端即可，其余代码不动。
诚实的代价：没有 LLM 二判，遇到发音很不标准时可能把「读对了」判成「再听一次」。对 6 岁场景这是可接受的——因为反馈不是「你错了」，而是「再听一次，慢慢来」。另外 ASR 偶尔会把英语单词听成中文，同样落到兜底分支。

选词原则

  • 具体可画：每个词都能用 ≤25 笔简笔画表达；抽象词（love / big / happy）一律不收。
  • 音节短：以 1–2 音节为主，仅 strawberry / watermelon / elephant / rainbow / ice cream 等孩子熟词放宽。
  • 颜色词用实物代表：red 画苹果、blue 画云和波浪、yellow 画太阳、green 画叶子——6 岁孩子靠具体物理解颜色，比画一个「涂红的圆」好懂得多。
  • 不教拼写：孩子不识字，屏幕上不显示单词文本。word 字段只给 TTS、给家长、给小智看；「问小智」屏顶部的小字也是给家长看的。
